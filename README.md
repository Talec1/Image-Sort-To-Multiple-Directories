# Image Categorizer

A Python application built with PyQt6 for efficiently sorting and categorizing images into different directories.

## Features
- Load images from a selected directory
- Create multiple category directories for sorting
- Preview images in a large display
- Navigate through images with Previous/Next buttons
- View thumbnails of recently categorized images
- Store sorting progress json
- Multiple category selection per image

## Requirements
```
PyQt6
Pillow
```

## Installation
1. Clone this repository
2. Install requirements:
```bash
pip install PyQt6 Pillow
```

## Usage
Run the application:
```bash
python img_sort1.py
```

1. Click "Get Images from" to select a folder with images to be sorted
2. Click "Send Images to" to create category folders to send images to
3. Use checkboxes to select 'categories' / 'directories' you want the image sent to.
4. Click "Send" to move current image to selected categories / directories
